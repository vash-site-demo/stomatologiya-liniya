# Стоматология «Линия»

Демонстрационный одностраничный сайт стоматологической клиники для портфолио. Это не сайт действующей клиники и не клиентская работа. Композиция новой версии ориентирована на предоставленный пользователем референс стоматологии, но тексты, контакты, врачи и отзывы референса не копируются.

## Возможности

- оригинальная композиция первого экрана с новой сгенерированной пациенткой, смотрящей в камеру;
- зафиксированный оффер о трёх сценариях и рассрочке без процентов;
- горизонтальная панель консультации и основная форма записи;
- интерактивное сравнение улыбки с ползунком и честной пометкой о визуальном эффекте;
- сгенерированный блок современного оборудования;
- шесть направлений лечения с автоматическим выбором услуги;
- интерактивный пример трёх сценариев лечения с клавиатурным управлением;
- модальное окно демо-скидки 10 % с автопоказом один раз за сессию;
- блоки врачей и отзывов без выдуманных людей и цитат;
- преимущества, галерея, контакты, FAQ и мобильное меню;
- анимация первого экрана и поддержка `prefers-reduced-motion`;
- проверка полей, локальное сохранение заявок и копирование текста записи;
- локальные изображения, шрифт и иконки.

Обе формы ничего не отправляют администратору. Данные сохраняются только в `localStorage` текущего браузера. Для настоящей записи нужно подключить канал связи клиники.

## Стек

HTML, CSS, JavaScript и Vite для локального запуска и сборки. Иконки — Lucide.

## Запуск

```bash
npm install
npm run dev
```

## Сборка и проверка

```bash
npm run build
npm run preview -- --port 7100
npm run test:browser
```

## Контент

Утверждённый оффер, состав интерфейса и работа форм — факты этого демонстрационного проекта. Цены, скидка, рассрочка и сценарии лечения являются содержимым макета, а не подтверждёнными условиями бизнеса. Для реального проекта необходимо заменить их данными клиники, добавить настоящие контакты, сведения о врачах, лицензиях, подтверждённые отзывы и правила обработки персональных данных.
